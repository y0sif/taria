# taria brand

- **Name**: taria (TUI + ARIA). Pronounced "TAH-ree-ah".
- **Tagline**: The tree, not the screen.
- **One-liner**: ARIA for terminals: an agent accessibility layer for TUIs.
- **Personality**: technical, minimal, standards-minded, pragmatic.
- **Voice**: precise and calm. Explain by analogy to web accessibility (the
  audience already knows ARIA). Never overclaim; the demo does the talking.

## Palette (dark-first, terminal-native)

- Accent: cyan `#22d3ee` (the classic terminal cyan, modernized)
- Surface: `#0b1020` / raised `#151b2e`
- Text: `#e2e8f0` primary, `#94a3b8` muted
- Semantic: success `#34d399`, warning `#fbbf24`, error `#f87171`

## Logo direction

A widget tree glyph inside a terminal frame: three nested rectangles connected
by tree edges, drawn in box-drawing characters (└─, ├─) so it reads as both
"tree" and "terminal" at a glance. Works as ASCII art in the README header
before any image asset exists.

## Don'ts

- Don't call it a "driver", "scraper", or "automation tool" — that's the
  competition's side of the terminal.
- Don't pitch against tmux with hostility; taria composes with those tools.
